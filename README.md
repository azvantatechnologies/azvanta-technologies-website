# Azvanta Technologies

Responsive startup landing page built with React, Vite, and Tailwind CSS.

## Run the project

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Values to replace

- Add the EmailJS Service ID, Template ID, and Public Key in `src/components/Contact.jsx`.
- Replace the placeholder social URLs in `src/components/SocialLinks.jsx`.
- Replace the portfolio image and project URL in `src/components/Portfolio.jsx`.
